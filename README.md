# Growthub Desktop

Download Growthub Desktop from [Releases](https://github.com/Growthub-OS/growthub-desktop/releases). No GitHub account is needed. This repository distributes installers; application source remains private.

## Install

**macOS (Apple silicon):** Download the DMG, open it, and drag Growthub into Applications. Open Growthub. If macOS asks for approval, after trying to open it go to System Settings → Privacy & Security → Open Anyway for Growthub, then confirm Open. This approves this application without disabling Mac security. Managed computers may require administrator approval.

**Windows (64-bit):** Download the EXE and follow its setup wizard. Windows or your organisation may block an unsigned installer. Smart App Control can prevent it from running; follow your computer’s security policy rather than disabling protection.

Official installation guidance: [Apple](https://support.apple.com/en-us/102445), [Microsoft](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions).

## Checksums

Each release includes SHA256SUMS. Installers are built from Growthub source and distributed as binary assets, not source archives.
